# Rigidity of the Midpoint Mean Value Property on Intervals of Fixed Length

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23608540.svg)](https://doi.org/10.5281/zenodo.23608540)

**Author:** Maksim Stepnov

**Publication:** Published in [The Curieux Review](https://www.curieuxreview.com/fall-winter-2026), November 2026 issue (Issue 13, Part 1), ISSN [3144-0231](https://www.curieuxreview.com/past-issues). Preprint available on Zenodo: [10.5281/zenodo.23608540](https://doi.org/10.5281/zenodo.23608540)

The mean value theorem guarantees a point where the derivative equals the average rate of change, but not where that point is. A classical converse says that if the midpoint always works, the function is a polynomial of degree at most two. This paper asks what happens when only one fixed interval length is required.

## Main results

- Parabolas are no longer the only solutions. There are infinitely many counterexamples of the form $e^{at}\cos(bt)$, and the smallest growth rate among them is $\alpha_1 = 5.5373565660\ldots$
- Any solution built from finitely many such modes that grows more slowly than $e^{\alpha_1 \lvert t \rvert}$ must be a polynomial of degree at most two, and $\alpha_1$ is sharp.
- An algebraic description using differentiation and translation operators reduces rigidity to showing that a certain explicit polynomial equals $z^3$.
- The phenomenon is specific to the midpoint.
